# 🗺️ Roadmap de Desarrollo - CommonPay

El desarrollo de **CommonPay** se rige bajo la metodología **Spec-Driven Development (SDD)** con **GitHub Spec Kit**. 

Para evitar duplicidades y garantizar la integridad de la hoja de ruta del proyecto, la planificación oficial y el estado de implementación de las funcionalidades se ha centralizado en el registro de especificaciones:

👉 **[Roadmap y Registro Oficial de Specs (specs/README.md)](file:///c:/Proyectos/mamalotapp/specs/README.md)**

Cualquier cambio, propuesta o nueva funcionalidad debe documentarse primero allí mediante el flujo regulado de GitHub Spec Kit (`/speckit.specify` -> `/speckit.clarify` -> `/speckit.plan` -> `/speckit.checklist` -> `/speckit.tasks` -> `/speckit.implement` -> `/speckit.converge`).
